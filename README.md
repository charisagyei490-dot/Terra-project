# Terra Project

## About the Game
Terra is a Python adventure game where players explore a world filled with exciting places and unique challenges. The journey takes players through various towns, such as Dream Ocean, Enchanted Forest, Starlight Village, and Crystal Cave. Each town features its own distinct story, secrets, and items to discover. 

Some locations remain locked until players meet specific requirements or collect enough resources. When a player attempts to enter a locked area, the game explains what items or coins are needed and allows them to decide whether to search for them. I am building this project step by step to improve my Python programming skills while creating a fun text-based RPG experience.

## How to Play
1. Download or clone this repository to your local machine.
2. Make sure you have Python 3 installed.
3. Open your terminal, navigate to this project directory, and run `python main.py`.
4. Follow the text prompts to explore the world!
